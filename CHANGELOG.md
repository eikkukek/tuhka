# Changelog

All changes to this project will be documented in this file.
## [0.1.10] - 2026-11-05
### Fixed
- Docs.
## [0.1.9] - 2026-11-05
### Added
- `bytemuck` `NoUninit` implementation for non-dispatchable handles and enums.
## [0.1.8] - 2026-11-04
### Changed
- Package metadata
## [0.1.7] - 2026-11-04
### Added
- Optional `bytemuck` feature that implements `Zeroable` for structs with no `StructureType` and
  `AnyBitPattern` for non-dispatchable handles.

## [0.1.6] - 2026-11-02
###  Changed
- Breaking changes in struct API
- Breaking changes in Device, Instance and Library functions.
- Doc changes
## [0.1.5] - 2026-05-18

### Fixed
- Fixed the "window" feature

## [0.1.4] - 2026-05-18

### Changed
- Breaking changes in struct API

## [0.1.3] - 2026-05-03
### Fixed
- Devices and instances not being clonable
## [0.1.2] - 2026-04-25

### Fixed
- Enum docs
- Missing enum variants
## [0.1.1] - 2026-04-25
### Added
- License

### Changed
- README.md
- Docs
